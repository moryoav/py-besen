# Support

Use GitHub issues in this repository for reproducible library bugs, protocol
compatibility reports, and focused feature requests.

For problems with Home Assistant entities, setup, or HACS, use the
[integration's issue tracker](https://github.com/moryoav/besen/issues) instead.

Before opening an issue:

- Check the latest release notes in `CHANGELOG.md`.
- Check the Bluetooth notes in `README.md`.
- Confirm the charger advertises as an `ACP#...` Bluetooth device and that no
  other app or bridge is connected to it.
- Remove charger PINs, private BLE addresses, private logs, and Wi-Fi details
  from anything you share.

For security concerns, follow `SECURITY.md` and do not post exploit details in a
public issue.

For electrical safety, wiring, breaker sizing, charger installation, or local
code questions, consult a qualified professional. This project cannot validate
or certify an electrical installation.
